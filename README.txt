飛鳥時代ダービー
================

■ 起動方法
  index.html をダブルクリックして、ブラウザ（Chrome / Edge / Safari 推奨）で開くだけ。
  インストールやサーバーは不要です。PC の横長画面向けに作っています。

■ 遊び方
  1. 「出航」を押すと、ホラ貝が鳴ってオージエンス10人が一斉に噂を始める。
  2. 時間内に噂を全部読み、一番に隋へ着く遣隋使を推理する。
  3. 右側のボタンで1人に賭ける。レースを見て結果発表。
  4. 3連勝すると小野妹子が手に入る。

■ 噂の読み方
  ・「AはBより速い／遅い」 … そのままの順位関係
  ・「調子いい」           … 2位以内に入る
  ・「重い」「不調」       … 1位にはなれない
  ・服の色の噂             … その色の服の遣隋使のこと
  噂を全部読み解けば、1位は必ず1人に決まります。

■ 音について
  ホラ貝・雅楽風BGM・ガヤガヤ音が鳴ります。右上の「音 ON/OFF」で消せます。
  ブラウザの仕様で、最初に「出航」を押したときから音が出ます。

■ 補足
  ・フォント（しっぽり明朝）はネット接続時に読み込まれます。オフラインでは端末の明朝体で表示されます。
  ・連勝記録と小野妹子の獲得状況は、そのブラウザ内にだけ保存されます。
